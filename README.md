# My Portfolio
HTML・CSS・JavaScriptを使用して制作した、個人ポートフォリオサイトです。

Webアプリケーション開発の学習内容や、これまでの制作実績を紹介しています。

## 公開サイト
https://kazuki77i.github.io/Portfolio/

## 使用技術
- HTaML5：ページの構造作成
- CSS3：デザイン・レスポンシブ対応
- JavaScript：スクロール操作の実装
- Git / GitHub：ソースコード管理
- GitHub Pages：Webサイトの公開

## 実装した機能
- About Me：自己紹介
- Skills：使用技術の一覧表示
- Projects：制作実績の紹介
- Contact：メール・GitHubへのリンク
- スマートフォン・PCに対応したレイアウト
- ページ上部に戻るボタン
- キーボード操作時のフォーカス表示
- アニメーション軽減設定への対応

## 制作実績
### Reservation Manager（予約管理アプリ）
Java・Spring Bootを使用した予約管理アプリケーションです。
予約情報の登録・一覧表示・更新・削除などの機能を実装しています。
GitHub：
https://github.com/kazuki77i/Reservation-Manager
