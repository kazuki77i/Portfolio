Projects

Reservation Manager

予約情報を管理するために制作している Webアプリケーションです。 予約管理の仕組みを学ぶことを目的に開発中。

使用技術

Java / Spring Boot / Maven / Git / GitHub

主な機能

  • 予約情報の登録（POST）
  • 予約一覧の取得（GET）
  • 予約情報の更新（PUT）
  • 予約情報の削除（DELETE）

開発で工夫した点

予約情報の登録・取得・更新・削除を それぞれ独立したAPIとして整理し、 HTTPメソッドの役割を意識して設計しました。

GitHubでコードを見る
